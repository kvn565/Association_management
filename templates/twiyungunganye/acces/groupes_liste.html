Comment ça marche ?
  1. Créez des groupes avec les menus autorisés (ex: "Comptabilité", "Direction", "Secrétariat").
  2. Assignez un groupe à chaque utilisateur via la page Membres → Modifier.
  3. Les utilisateurs avec un groupe ne verront que les menus cochés dans leur groupe.
  4. Les utilisateurs sans groupe conservent leur accès par défaut (admin = tout).
